## Información General

**EduConnect** es una plataforma web para la gestión integral de tutorías académicas. Su objetivo es facilitar la comunicación y coordinación entre estudiantes y tutores, permitiendo consultar tutores, gestionar horarios, programar sesiones y mantener un historial de las tutorías realizadas.

El sistema cuenta con tres roles principales:

- **Estudiante:** búsqueda de tutores, consulta de horarios, programación y gestión de sesiones.
- **Tutor:** administración de perfil, horarios, sesiones y registro de atención a estudiantes.
- **Administrador:** aprobación de usuarios, administración de estudiantes y tutores y generación de reportes.

El proyecto se desarrolla aplicando metodologías ágiles, principalmente **SCRUM**, utilizando **Git Flow** para el control de versiones, un tablero **Kanban** para la gestión de tareas y **Docker/Docker Compose** para la contenedorización del frontend y backend.

---

## Objetivo

Desarrollar una plataforma web completa que permita gestionar sesiones de tutoría académica mediante tres módulos diferenciados:

- Estudiante.
- Tutor.
- Administrador.

La plataforma incorpora funcionalidades de registro, autenticación, programación, administración y seguimiento de sesiones.

El proyecto contempla como mínimo dos sprints completos y la documentación correspondiente de la metodología SCRUM.
